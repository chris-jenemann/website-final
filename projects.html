      Yellowstone Simulator

      OOP

      For the final Project of my university's Java class, we were tasked to design an ecosystem simulated through OOP programming. My idea for Yellowstone (#ImFromMT) was chosen, so my teammates and I set out to design the system in a good OOP style. I started by creating a simple UML chart in Lucid to create a clear direction for the team. The sim revolved around a driver class that runs a simple tick clock and keeps track of every organism's state. Each organism is derived from an organism's parent class, and through inheritance, they are separated into more specific animal or plant classes. The simulations also featured dynamic seasons that affected animal and plant reproduction and lifestyle.

      The biggest take aways from this project, was first the importance of strong system design along side good team cordination. creating a stronger plan would have made this project quite a bit easier. Having a stong understading of git is a also nessecary for large group efforts like this is also essential. Github for those who are interested.
